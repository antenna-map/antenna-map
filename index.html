Ключ используется только в этом браузере и не записывается в файлы сайта. После геокодирования скачайте JSON с координатами.

Исходные адреса загружаются из файла objects.json. Изменения хранятся только в этом браузере. Данные не синхронизируются и могут исчезнуть при очистке браузера. Регулярно делайте резервную копию CSV.

Загружаем Яндекс Карты…

Карта использует API Яндекса через интернет. Для массового определения координат используйте кнопку в левой панели. Координаты сохраняются в браузере; для отображения всем посетителям экспортируйте JSON и замените objects.json в GitHub. Условия бесплатного использования и ограничения ключа необходимо проверить в кабинете Яндекса.
