Проверить отдельный ключ API Геокодера

Проверка официального адреса /1.x/. Ключ вводится только в этом браузере, не записывается в HTML или localStorage. Запрос может быть заблокирован браузером (CORS). Не используйте секретный ключ сервисного аккаунта.

Карта использует API Яндекса через интернет. Приложение автоматически пытается определить расположение по адресу. Если геокодирование не разрешено для ключа, метка не появится. Условия бесплатного использования и ограничения ключа необходимо проверить в кабинете Яндекса.
